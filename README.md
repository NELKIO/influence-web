# Influence Web

Фанатский браузерный ремейк пошаговой стратегии «Влияние» (Influence) от Teremok Games.
Играть: https://nelkio.github.io/influence-web/

Весь код, графика и звуки — оригинальные; проект не связан с Teremok Games.
Механики воспроизведены так, чтобы партии игрались как в оригинале.

## Разработка

```bash
npm install
npm run dev      # локальный сервер
npm test         # unit-тесты
npm run e2e      # Playwright
npm run build
```
