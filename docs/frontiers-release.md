# План обновления: Тьма, рубежи и раздел территорий

1. Зафиксировать календарь до смены ротации, сохранить старые построители. Убрать из выбора Мосты, Сокровищницу и Песочные часы; проверить размер каталога (32).
2. При сдаче раздавать близкие по силе доли с разницей не больше одной клетки. Слегка предпочитать более поздний фактический ход, не трогать боевые кости. Проверить внеочередную сдачу, смену раунда, малый остаток и воспроизведение в сети.
3. Добавить Дальний берег, Безлунную долину, Искры, отдельную карту только со слабыми разведчиками, две карты на удержание рубежей и седьмой новый старт для полной строки каталога. Проверить доступность разных направлений атаки и реальные партии.
4. Рубежи: три открытые цели, две нужно удержать до своего следующего хода. Отобразить их в игре и предпросмотре; разрешить перегенерацию варианта до старта, но не карты дня. Проверить прерванное удержание, ботов, сохранение и сетевое состояние.
5. Режимы → Экспериментальные: абсолютная тьма и сигнальные огни, оба по умолчанию выключены. Не раскрывать карту в предпросмотре или при передаче устройства. Огонь действует до следующего хода: владелец видит окрестности, остальные — источник. Проверить игру на одном устройстве, сохранение и сетевой обмен.
6. Запустить сборку, unit- и браузерные тесты, проверить diff, опубликовать в GitHub, проверить GitHub Pages и отдаваемую сборку. Массовые симуляции — только в разрешённом каталоге сервера с последующей уборкой. «Приказ в резерве» не входит в релиз.
